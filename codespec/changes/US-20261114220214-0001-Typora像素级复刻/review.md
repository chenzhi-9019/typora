## 四、一般

| 编号 | 意见 | 复验 | 处置 |
|---|---|---|---|
| R1 | 菜单顶级标签渲染成「文件 编辑 …」，原版是「文件(F) 编辑(E) …」 | 截图放大确认；查运行时 MenuItem.label 已是 文件(F)，是 Chromium 在绘制 CJK 标题时把 (&F) 整段吃掉 | 接受。标签改为字面量 文件(F)，重建后与原版逐字一致；代价是 Alt 助记键失效，已记入遗留 |
| R2 | 勾选类菜单项会翻转两次（主进程 patch 一次、渲染端 patch 一次） | 读 src/main/menu.ts 的 toggleSetting 与 commands.ts 的 applyBoolean 确认重复 | 接受。改为「渲染端拥有设置」：主进程只发命令，patch 回流后由 syncMenuState 回写勾选态 |
| R3 | 文件 > 关闭 由主进程直接关窗，脏检查来不及 | 读 performWindowAction 确认 | 记为 V4 遗留，不在本轮修（需要把关闭改成异步握手） |
| R4 | 菜单设计里「段落」我 brief 写的 34 项与实际树不符 | 以 MENU 树为准：顶层 41 项含 5 条分隔线、叶子 44 个 | 反驳。brief 数字是笔误，实现正确 |

## 六、第五、六轮补做后的复核

| 能力 | 实现位置 | 我的复验 |
|---|---|---|
| 导出 PNG | 主进程隐藏窗 + capturePage | 子智能体实测产出 25KB PNG、magic 正确、采样 10 色 |
| 新建窗口 / 关闭握手 | src/main/window.ts（WeakSet 按窗口实例） | 读代码确认按实例隔离；另加了 5 秒超时放行避免应用无法退出 |
| CRLF / LF | src/main/eol.ts + fs:write-file | 先归一化再转换，结构上不可能出现重复回车 |
| showBr / 智能标点 / 首行缩进 / 保留单换行 | editor 渲染层 + 序列化反向映射 | 子智能体实测开关往返不污染源码 |
| 图片根目录 | fs:copy-file + commands.ts 相对路径 | 实测去重后缀 + 相对路径 assets/photo-1.png |
| 多标签 | stores/document.ts + TabBar.vue | 截图确认两标签 + 切换 + 标题更新；单文档时不渲染，像素比对无回归 |

## 七、遗留

- 「文件 > 导入」无 Pandoc 导入器（V5）；「选择编码重新打开」除 UTF-8 外 22 种编码不生效（V6）。
- 顶级菜单为字面量「文件(F)」形式，Alt 助记键不可用。
- 字数统计与原版差 3 词（V1）。
- 六组特殊加速键未做真机手工点击验收（S2）。
