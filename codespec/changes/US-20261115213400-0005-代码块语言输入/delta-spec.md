# 代码块语言输入 Spec Delta

## Purpose

现状：键入 ``` 与一个空格后，段落立刻变成代码块，光标直接落进代码体，语言只能事后用鼠标点右下角胶囊再输入。原版把「想写代码块」和「要写哪种语言」放在同一次输入里完成——列表当场出现、输入即筛、回车即成块。本变更补齐这条输入路径。

## ADDED Requirements

### Requirement: 新建代码块时即时选择语言

段落中输入三个及以上反引号或波浪号后再键入一个空格时，应用 SHALL 在段落尚未转换的前提下弹出语言选择列表，列出编辑器支持高亮的全部语言，并以空格之前已键入的片段作为初始筛选文本；列表 SHALL 随输入做不区分大小写的子串筛选，名称以输入开头的条目排在前面、其余按名称长度再按字典序排列；列表 SHALL 支持方向键移动高亮、回车确认、Esc 与失焦取消。

#### Scenario: 空格唤起全量语言列表

- **WHEN** 光标位于空段落，依次键入 ``` 和一个空格
- **THEN** 段落仍是普通段落，编辑区在其下方弹出语言列表，按名称列出全部可高亮语言（含 js / py / ts 等常用别名），且默认没有高亮项

#### Scenario: 输入即筛

- **WHEN** 列表打开后键入 scr
- **THEN** 列表只剩名称中含有 scr 的语言，javascript、coffeescript 等以 scr 开头的排在前，其余按名称长度、再按字典序排列

#### Scenario: 方向键移动高亮

- **WHEN** 列表打开后按两次方向键下
- **THEN** 高亮停在第三项，列表滚动到该项可见，段落文本不因这次按键而改变

#### Scenario: 回车成块并着色

- **WHEN** 高亮停在 javascript 时按回车
- **THEN** 该段落变为代码块并立即以 javascript 语法着色，光标位于代码体首行，Markdown 里写成 ```javascript 围栏

#### Scenario: 直接回车不指定语言

- **WHEN** 列表打开后未键入字符、未移动高亮，直接按回车
- **THEN** 生成无语言的代码块，Markdown 里写成不带信息串的 ``` 围栏，光标位于代码体首行

#### Scenario: 取消

- **WHEN** 列表打开时按 Esc，或点击编辑区其它位置
- **THEN** 列表关闭，且不生成代码块，段落保留当时已键入的文本

#### Scenario: 不沿用上次语言

- **WHEN** 上一个代码块的语言是 python，用户另起一段新建代码块并直接回车
- **THEN** 新代码块没有语言，不会带出 python

### Requirement: 既有代码块的语言修改沿用同一列表

点击已存在代码块右下角的语言胶囊时，应用 SHALL 弹出与新建时相同的语言选择列表，胶囊原有语言作为初始筛选文本；回车或点选列表项 SHALL 把该语言写回围栏，并立即按新语言重新着色。

#### Scenario: 点开胶囊列出全量语言

- **WHEN** 点击一个语言为空的代码块的语言胶囊
- **THEN** 胶囊获得焦点，其下方列出全部语言，胶囊显示占位文案「代码块语言」

#### Scenario: 改语言后重新着色

- **WHEN** 在胶囊里键入 py 并回车
- **THEN** 围栏信息串变为 py，代码块按 python 语法重新着色，胶囊显示 py

## Impact

- 基线 `codespec/specs/spec.md` 里没有任何一条需求规定代码块语言的选择方式（仅在「编辑区所见即所得」与「数学与图表」里提到代码块渲染），因此本次全部为 ADDED，无 MODIFIED / REMOVED / RENAMED。
- 与既有实现的冲突：US-20261115204338-0004 交付的版本是「空格即转块、转完光标进代码体、带出上次语言」，其 delta 至今未并回基线。本次把前两点改成「空格只弹列表、回车才成块」与「不带出上次语言」。
- 保留不动的入口：键入 ```js 后**直接按回车**（不打空格）仍立即生成 lang=js 的代码块，`scripts/parity/checks.mjs` 的 input.fence 与 input.fence-no-autopair 两条断言因此不受影响。
- 兼容性：列表只在输入过程中出现，不进入 Markdown；没有任何既有文档会被改写，序列化仍是普通围栏。
