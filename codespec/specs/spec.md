# Typora 桌面编辑器 Specification

## Purpose

为 Windows 桌面提供一款与 Typora 1.14.15 像素级一致的 Markdown 编辑器：自定义窗口外壳、可折叠文件侧栏、所见即所得编辑区、五套内置主题、数学公式与图表渲染、HTML 与 PDF 导出。目标是让用户在自有工程里获得与原版 Typora 相同的视觉与交互体验。

## Requirements

### Requirement: 应用窗口与外框

应用 SHALL 以单个原生（Windows）窗口呈现，默认 1000x760，最小 400x300，标题随当前文档名变化，并保留原生菜单栏「文件 / 编辑 / 段落 / 格式 / 视图 / 主题 / 帮助」。

#### Scenario: 启动应用

- **WHEN** 用户启动应用且没有上次打开的文档
- **THEN** 出现一个 1000x760 的窗口，标题为 Typora，菜单栏为中文一级菜单，编辑区为空并可直接输入

#### Scenario: 打开文档后标题更新

- **WHEN** 用户打开 mydoc.md
- **THEN** 窗口标题变为「mydoc.md - Typora」

### Requirement: 文件与工作区

应用 SHALL 支持打开单个 Markdown 文件、打开文件夹并以树形展示其中内容、新建文件、保存与另存为，并在存在未保存修改时阻止直接丢弃。

#### Scenario: 打开文件夹

- **WHEN** 用户选择「文件 > 打开文件夹」并选中一个目录
- **THEN** 侧栏显示该目录的树形结构，目录可展开折叠，目录优先、同类按名称自然排序

#### Scenario: 未保存修改拦截

- **WHEN** 当前文档有未保存修改，用户执行新建或打开文件
- **THEN** 弹出「保存 / 放弃 / 取消」三选，选「取消」时当前文档保持不变

### Requirement: 编辑区所见即所得

编辑区 SHALL 在非源码模式下把 Markdown 直接渲染为排版后的文档并允许原地编辑，在源码模式下提供带行号与语法高亮的 Markdown 源码编辑。

#### Scenario: 渲染块级元素

- **WHEN** 文档包含标题、段落、列表、任务列表、引用、代码块、表格、分割线、YAML front matter
- **THEN** 编辑区按 Typora 的块结构渲染，且样式取自当前主题的 CSS 变量

#### Scenario: 切换源码模式

- **WHEN** 用户点击状态栏的源码模式按钮
- **THEN** 编辑区切换为等宽字体的 Markdown 源码视图并显示行号，再次点击切回

### Requirement: 代码块语言选择列表

在空段落键入三个及以上反引号或波浪号后再加一个空格时，应用 SHALL 保持该段落为普通段落并弹出语言列表，列出编辑器支持高亮的全部语言；列表 SHALL 按输入做不区分大小写的子串筛选，名称以输入开头的条目排在前、完全匹配的别名排在最后，其余按名称长度再按字典序；列表 SHALL 支持方向键移动高亮、回车确认、Esc 与失焦取消。

#### Scenario: 空格唤起语言列表

- **WHEN** 光标位于空段落，依次键入三个反引号和一个空格
- **THEN** 段落仍是普通段落，其下方弹出语言列表，按名称列出全部可高亮语言（含 js / py / ts 等别名），且没有默认高亮项

#### Scenario: 输入即筛

- **WHEN** 列表打开后键入 scr
- **THEN** 列表只剩名称中含 scr 的语言，javascript 排在最前

#### Scenario: 回车成块并着色

- **WHEN** 列表打开后键入 py，按一次方向键下选中 python 并回车
- **THEN** 段落变为代码块，围栏写成 ```python，立即以 python 语法着色，光标位于代码体首行

#### Scenario: 直接回车不指定语言

- **WHEN** 列表打开后未键入字符、未移动高亮，直接按回车
- **THEN** 生成不带语言的代码块，围栏是不带信息串的 ```，光标位于代码体首行

#### Scenario: 取消

- **WHEN** 列表打开时按 Esc 或点击编辑区其它位置
- **THEN** 列表关闭且不生成代码块，段落保留已键入的文本

#### Scenario: 不沿用上次语言

- **WHEN** 上一个代码块的语言是 python，用户再新建一个代码块并直接回车
- **THEN** 新代码块没有语言，不会带出 python

### Requirement: 代码块语言修改

点击已存在代码块右下角的语言胶囊时，应用 SHALL 弹出与新建时相同的语言列表，并以胶囊现有语言作为初始筛选文本；回车或点选列表项 SHALL 把该语言写回围栏信息串并立即重新着色。

#### Scenario: 点开胶囊

- **WHEN** 点击一个语言为空的代码块的语言胶囊
- **THEN** 胶囊获得焦点，其下方列出全部语言，胶囊显示占位文案「代码块语言」

#### Scenario: 改语言后重新着色

- **WHEN** 在胶囊里键入 py 并回车
- **THEN** 围栏信息串变为 py，代码块按 python 语法重新着色，胶囊显示 py

### Requirement: 大纲与字数统计

应用 SHALL 从当前文档提取 h1 至 h6 生成大纲，并在状态栏实时显示词数、字符数与非空白字符数。

#### Scenario: 大纲随输入更新

- **WHEN** 用户新增或删除一个标题
- **THEN** 侧栏大纲在 300 毫秒内同步为新的标题列表，点击大纲项可跳转到对应行

#### Scenario: 字数统计

- **WHEN** 用户在空文档中输入「你好 world」
- **THEN** 状态栏词数显示为 3（中文按字计、英文按词计）

### Requirement: 主题

应用 SHALL 内置 github、night、newsprint、pixyll、whitey 五套主题，主题切换即时生效且不刷新文档。

#### Scenario: 切换主题

- **WHEN** 用户在「主题」菜单选择 night
- **THEN** 窗口背景、侧栏、编辑区正文颜色与字体同时切换为暗色主题取值，当前文档内容与光标位置不变

### Requirement: 菜单栏与 Typora 完全一致

应用 SHALL 提供与 Typora 1.14.15 同构、同序、同文案的七个顶级菜单（文件 / 编辑 / 段落 / 格式 / 视图 / 主题 / 帮助），其下每一条菜单项都存在且可点击，可执行项必须真的生效。

#### Scenario: 菜单结构与原版一致

- **WHEN** 用户依次展开七个顶级菜单
- **THEN** 每个菜单的条目顺序、中文文案、分隔线位置、加速键与原版逐条对应，主题菜单列出 github / night / newsprint / pixyll / whitey 五套并显示当前选中项

#### Scenario: 菜单命令真的生效

- **WHEN** 用户在「段落」菜单点「下方插入行」而光标位于表格内
- **THEN** 当前表格在光标所在行下方新增一行，编辑器内容随之变化

#### Scenario: 勾选类菜单项与设置同步

- **WHEN** 用户取消勾选「视图 > 状态栏」
- **THEN** 状态栏立即隐藏，设置落盘为 `showStatusBar: false`，下次启动仍保持隐藏

### Requirement: 应用图标

应用 SHALL 使用与原版一致的图标：窗口图标、任务栏图标与打包产物的可执行文件图标均为 Typora 的图标，Markdown 文件关联使用原版的 .md 文件图标。

#### Scenario: 任务栏图标

- **WHEN** 应用运行时查看任务栏
- **THEN** 显示的是 Typora 的图标而不是 Electron 默认图标

### Requirement: 滚动条

编辑区与侧栏的滚动条 SHALL 复刻原版样式：12px 宽的透明轨道，半透明滑块以 4px 透明左边框收窄，悬停时滑块回到满宽。

#### Scenario: 悬停滚动条滑块

- **WHEN** 鼠标悬停在编辑区右侧滚动条的滑块上
- **THEN** 滑块从 8px 变宽到 12px，颜色由 rgba(0,0,0,.3) 变深，轨道出现极淡的底色

### Requirement: 数学与图表

编辑区 SHALL 渲染行内与块级数学公式以及 mermaid 图表。

#### Scenario: 渲染块级公式

- **WHEN** 文档中出现 ```math 围栏或 $$...$$ 块
- **THEN** 编辑区以排版后的公式替换源码并在切换回源码模式时还原为原文

### Requirement: 导出

应用 SHALL 把当前文档导出为独立 HTML 文件与 PDF 文件，导出结果保留当前主题的排版。

#### Scenario: 导出 PDF

- **WHEN** 用户执行「文件 > 导出 > PDF」并选择保存路径
- **THEN** 生成一个 A4 页面尺寸的 PDF，正文排版与当前编辑区一致

### Requirement: 设置持久化

应用 SHALL 把主题、字号、行高、侧栏状态、最近打开的文件夹等设置持久化到用户数据目录，并在下次启动时恢复。

#### Scenario: 恢复上次会话

- **WHEN** 用户上次退出前停留在 night 主题且侧栏处于展开状态
- **THEN** 再次启动时主题为 night、侧栏展开，并自动载入上次打开的文件夹
